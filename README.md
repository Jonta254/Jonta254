## About

I turn early-stage ideas into clear, responsive, production-ready applications. My work spans product thinking, interface design, full-stack development, third-party integrations, testing, and launch.

I am especially interested in products that connect digital identity and payments with useful everyday experiences. I care about the less-visible details that make software trustworthy: secure authentication, explicit permissions, verified payment states, accessible interfaces, and graceful failure recovery.

## How I work

- Start with the real user journey and the failure cases, not just the happy path.
- Keep interfaces legible, responsive, accessible, and purposeful.
- Treat authentication, permissions, and payment confirmation as product features.
- Ship with documentation, verification, and a clear path for continued iteration.
